# 设备故障快速记录系统 V1.1

正式网址：https://check.saka77.cn/

React + TypeScript + Vite。仅更新本仓库，由原GitHub Actions测试、构建并发布GitHub Pages。域名和DNS保持不变，不涉及game.saka77.cn或主域名项目。

## 快速记录
花园 → T1–T9 → 1–8号；默认记录“不亮”。塔内勾选“不受控”后点灯号即可记录，成功后自动返回塔选择并取消勾选。花园允许重复编号。

外围灯包含7个区域、27个灯具；绿色为当天未标记，点击变红并记录Roof与编号，再点红色取消当天有效标记。仅操作今天，历史查看不影响操作日期。删除、撤销及刷新后红绿状态均由当天记录派生。城堡继续保留待配置页。

## 数据安全
存储键equipment-check-v1保持不变，旧记录原样读取，不补写故障类型。按上海时间分日；最新在上；单条删除、本次会话撤销新增、历史查看、清空二次确认、复制所选日期和导出全部历史CSV保留。复制及CSV包含新记录故障类型、Roof和区域信息。

记录仅保存在当前设备、浏览器和域名，不跨设备同步。请定期导出CSV。不要清除网站数据。PWA升级仅删除本工具旧Cache Storage，保留localStorage；可点击新版本提示刷新。Safari分享 → 添加到主屏幕。

## 开发与部署
Node 22+；npm ci；npm test；npm run build；npm run dev。

独立GitHub Pages，工作流.github/workflows/pages.yml负责推送main后的测试、构建与发布。Pages自定义域名check.saka77.cn，启用强制HTTPS。网页运行无需ChatGPT登录。

## 测试范围
10项模型测试覆盖默认故障、不受控、重复花园记录、完整27灯映射与切换、删除派生状态、上海午夜隔离、旧数据只读兼容、复制和CSV。浏览器实测塔选择、故障复位、外围灯多选取消、刷新红色保留、删除及撤销联动。320/390宽度Chrome内嵌预览检查长名称、按钮与水平溢出，不等同实际iPhone Safari真机测试。
